# Privacy policy

Bridge Timer stores its settings, tournament profiles, display preferences and recovery state locally on the user's computer.

The application starts a local HTTP server bound to `127.0.0.1` so the embedded WebView2 control can load the application interface. This loopback communication stays on the local computer.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

Bridge Timer includes no analytics, advertising, telemetry or remote account system.

The Microsoft Edge WebView2 Runtime is a Microsoft system/runtime component and is subject to Microsoft's own terms and privacy documentation.

## Local data

Bridge Timer may store data under `%LOCALAPPDATA%\BridgeTimerWebView2` and in its WebView2 data directory.

To remove Bridge Timer, delete `BridgeTimer.exe`. To remove saved settings as well, delete `%LOCALAPPDATA%\BridgeTimerWebView2`.
