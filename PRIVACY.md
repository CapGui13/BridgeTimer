# Confidentialité — BridgeTimer Light

BridgeTimer Light s'exécute dans votre navigateur. Les réglages et données de session peuvent être conservés localement dans le navigateur (localStorage) pour faciliter la reprise. L'application peut utiliser les API natives du navigateur pour le plein écran et pour empêcher la mise en veille lorsqu'elles sont disponibles.

Le site public n'exige pas de compte utilisateur et n'embarque pas de service d'analytics ou de télémétrie applicative. L'hébergement GitHub Pages peut être soumis à la politique de confidentialité de GitHub.

Pour effacer les réglages enregistrés, supprimez les données de site du navigateur pour capgui13.github.io.
