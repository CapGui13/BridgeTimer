# Bridge Timer 1.7.4

First public open-source release prepared for code-signing onboarding.

Highlights:

- embedded WebView2 desktop window;
- dark Windows title bar from first display;
- Per-Monitor DPI Awareness V2;
- projection/monitor selection and fullscreen support;
- configurable positions, breaks and finish timing;
- temporary messages;
- three named profiles;
- import/export of `.bridge-timer` settings;
- Accent, Background, Menu and Text colors;
- local settings and session recovery;
- Windows product/version metadata and application manifest.
