# BridgeTimer Light — chronomètre de bridge en ligne

**[Ouvrir BridgeTimer](https://capgui13.github.io/BridgeTimer/)**

La version publique de BridgeTimer fonctionne directement dans un navigateur récent, sans installation ni téléchargement d'application Windows.

Fonctionnalités : formats Paires et Match par 4, paramétrage des tours et des donnes, chronomètre, pause/reprise, plein écran, messages et écrans de fin.

Ce dépôt sert uniquement à la publication de **BridgeTimer Light**. Le code et les outils de développement de la version complète Windows sont conservés dans un dépôt privé distinct et ne sont pas distribués ici.

**Limite technique :** un site HTML/JavaScript exécuté dans le navigateur peut toujours être inspecté ou enregistré par les visiteurs. Aucun exécutable Windows n'est distribué sur ce dépôt.
